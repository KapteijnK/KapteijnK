## Achtergrond

Vanaf ik ongeveer 9 jaar oud was had ik al interesse in computers (voornamelijk gaming) & technologie. Ik vind het leuk om aan dingen te knutselen en een oplossing voor dingen te zoeken. Toen ik ongeveer 12 jaar oud was kreeg ik mijn eerste PC van mijn ouders.

Toen begon ik een beetje dingen te leren over computeronderdelen enzovoort, ik begon bekend te worden met termen zoals CPU, GPU, RAM, Moederboerd, Exhaust fans, RGB, ARGB, intake fans en nog veeeeel meer! Ik kwam er op die manier al snel achter dat de PC die ik dat moment had niet aan mijn eisen voldeed (Ik speel voornamelijk veel story games zoals, RDR2, GTA V, Last of Us enzovoort) dus wou ik beter. Vanaf 2021 ging ik op PCPARTPICKER heel veel verschillende builds maken totdat ik de perfecte combo had gevonden.

Uiteindelijk toen ik de goede combo had bouwde ik die zelf (Specs vind je hieronder) dit werd mijn eerste PC build en hiermee groeide mijn interesse in computers meer. Uitendelijk wou ik meer weten hoe je scripts enzovoort schreef dus ben ik begonnen aan de Bit Academy in Groningen nadat ik de middelbare school had afgemaakt!

## Mijn Projecten

Er zijn twee afgelopen projecten waar ik het meest trots op ben, die projecten vind je gelinkt hieronder!

### Dorpsvereniging Zuidbroek

Wij hebben de opdracht gekregen van Occo om een website te maken voor Dorpsvereniging Zuidbroek voor hun 30 jarig bestaan. Ze waren toe aan een nieuwe website aangezien hun oude website erg verouderd was, en ze waren toe aan iets nieuws.

Voor 3 van ons is dit ons aller eerste project voor een Opdracht gever, best spannend dus. Als je fouten in deze opdracht ziet laat het ons gerust weten en dan zullen we het zo spoedig mogelijk fixen!

Vindt de repository [Hier](https://github.com/KapteijnK/Dorpsvereniging-Zuidbroek)

### Bitbin 

De Bitbin is een project gemaakt door ons in opdracht van Reygan Leito, de opdracht was om een Bit versie van Pastebin te maken. Om onder alle Bit developers in Nederland makkelijk code te kunnen delen zonder andere externe communicatie platforms (zoals Discord, Mattermost, Microsoft Teams etc) te gebruiken waardoor alle code & kennis geheim blijft binnen het eigen bedrijf.

Vindt de repository [Hier](https://github.com/KapteijnK/BitBin-Scrum-2)
